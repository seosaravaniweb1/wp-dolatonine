# پوشه ترجمه‌ها

متن‌های قالب فارسی و مستقیم در کد نوشته شده‌اند، بنابراین برای کارکرد سایت
هیچ فایل ترجمه‌ای لازم نیست و این پوشه می‌تواند خالی بماند.

اگر روزی خواستید قالب را چندزبانه کنید، فایل‌های `.po` / `.mo` را با
دامنه متنی `dolat-online` اینجا قرار دهید؛ تابع `load_theme_textdomain()`
در `functions.php` خودکار آن‌ها را بارگذاری می‌کند.
